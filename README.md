## Building

1. Install Rust from [rustup.rs](https://rustup.rs/).
2. Install the **"Desktop development with C++"** workload, which Rust needs for linking. Get it from the [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) page (or tick it in the Visual Stuio Installer if you already have Visual Studio).
3. Run `Build.bat`.
4. The built app is at `target\release\cayo_perico_replay_glitch.exe`.
5. Or you can get a alr built ver from the releases on my [GitHub](https://github.com/yeno-why/Cayo-Perico-Replay-Glitch/releases/tag/1.0.0)
